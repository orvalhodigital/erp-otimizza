# Seeds do Banco de Dados

Este diretório contém os scripts de carga de dados controlados para desenvolvimento e testes.

## Conteúdo Planejado
- `001_initial_accounts_and_categories.sql` ou `.ts`: Categorias financeiras padrão (Receita de Vendas, Serviços Recorrentes, Despesas Fixas, Transferências) e conta financeira inicial (Caixa Geral).
- Os seeds são executados exclusivamente em ambientes de desenvolvimento e teste, nunca em produção.
